# 황리단길·대릉원 일대 보행 혼잡 관제 (웹 시연)

설치 없이 웹 브라우저에서 여는 관제 화면 시연판입니다. 미리 계산한 하루(행사 날, 평일, 주말)를 다시 보여 줍니다.

- 화면의 관광객 수와 혼잡은 모두 공개 통계를 바탕으로 만든 합성 시나리오로 계산한 결과입니다. 실제 관광객 데이터가 아닙니다.
- 관광객 수를 바꾸거나 처음부터 계산하는 실시간 시연은 시연용 실행 파일(Windows)에서만 할 수 있습니다.
- "운영 효과 (10/22 평가)" 칸의 숫자는 10월 22일 보고 때의 비교 결과입니다. 지금 화면의 결과가 아닙니다.

## 보는 법

1. 페이지를 열고 잠깐 기다리면 지도 위에 "시나리오 설정" 창이 뜹니다.
2. 날과 시작 시각을 고르고 "미리 계산한 하루 보기"를 누릅니다. 고른 시각에 멈춘 채로 열립니다.
3. "재생"을 누르면 움직이고, 한 번 더 누르면 멈춥니다. 배속은 ×30~×600이고, "1시간 건너뛰기"를 누르면 한 시간 뒤 시각으로 갑니다.
4. 오른쪽 "시간대별 추이" 그래프를 누르면 그 시각으로 갑니다.
5. 오른쪽 "우회 안내"의 끔·켬을 누르면 같은 시각, 안내를 켠(또는 끈) 결과로 바로 바뀝니다.
6. 다 봤으면 지도 위 오른쪽의 "다시 보기 끝내기"를 누릅니다. 다른 날을 고를 수 있습니다.

- 전체 화면: F11 (한 번 더 누르면 돌아옵니다)
- Chrome이나 Edge에서 가장 잘 열립니다. 열 때 파일을 받느라 조금 기다려야 합니다.
